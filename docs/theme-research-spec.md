# 题材赚钱效应与预案候选规则

题材判断采用“可解释指标与系统建议 + 人工确认或调整”。四板定义为连续四个交易日收盘涨停。首个候选模式是：在 T 日收盘后，从 T 日已确认强势的题材中筛出当日首板涨停股，作为下一交易日观察二板机会的候选。

这些是研究功能的产品口径，尚未实现或验证为有效交易策略。指标用于解释市场现象；模式是否有效，需要用保留当时信息的历史样本和后续观察另行验证。页面组织见 [产品方案](product-plan.md)，开发顺序见 [实施计划](delivery-plan.md)。

## 时间和数据身份

| 名称 | 定义 |
| --- | --- |
| T | 当前研究或预案所依据的交易日 |
| T+1 | 对应市场交易日历中的下一交易日，不是自然日加一，也不是下一条导入记录 |
| as_of | 本次判断允许使用信息的最晚时刻；盘中与盘后判断分别记录 |
| U(g,s) | 在交易日 s、指定截止时刻已知并采用的题材 g 成员集合 |
| C(g,s) | U(g,s) 中 s 日经核验收盘涨停的股票集合，同一股票在该集合内只计一次 |
| K(i,s) | 股票 i 在 s 日收盘时的连续涨停板数；无法确认时为未知 |
| W | 明确配置的交易日观察窗口；展示起止日期、应有天数和有效天数 |

每份事实或结论保留证券/题材稳定 ID、业务日期、可知时间、来源、数据修订版本和规则版本。原始资料板块、供应商概念板块、研究题材、自建盯盘组分别建模；名称相同不自动合并。

题材归属允许多对多，并记录生效区间、当时可知时间、来源和人工调整。资料中的题材词、股票涨停原因和关键词匹配先作为归属线索，不能直接当作已确认成员。若已知的只是导入涨停名单，应显示“样本内数量”；缺少完整题材成分时，不计算冒充全板块的上涨广度或涨停密度。

## 涨停与连板事实

1. 涨停识别使用当日原始收盘价、当日适用涨停价、证券状态和市场规则；价格采用统一最小报价单位或精确十进制比较。复权价格不能直接与原始涨停价比较。
2. 无涨跌幅限制日单独分类，不能把大于某个固定百分比的上涨记为涨停。不同市场、证券类型和历史日期可能适用不同规则。
3. 市场休市不占交易日；已确认停牌的市场交易日不满足“当日收盘涨停”，中断本方案的连续板序列。缺行情或缺交易日历属于未知，不能直接写成断板。
4. 保存原始连板文本，同时分别保存连续板数、区间交易日数、区间涨停次数。例如“10 天 2 板”不能代替连续板数。
5. 四个真实交易日都确认收盘涨停，可以确认至少四板；判定“首次达到四板”还需要此前状态足以证明 K 从 3 变为 4。此前历史缺失时，不猜测首次日期。
6. 区分“新达到三板/四板的事件”和“当前三板及以上/四板及以上的股票”。同一只股票从四板走到五板，不再记作一只新四板股。

旧项目基于相邻已导入日寻找四板的逻辑不能直接沿用。缺一日资料时，应提示补齐或待核验，不跳过缺口形成连续四板。

交易规则须按历史日期与实际生效范围版本化。上交所 2026 年修订规则发布页明确生效日期，并单列暂缓实施条文；不能只按文件发布时间套用规则。[上交所发布页](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml) 创业板规则资料也区分通常的涨跌幅限制与首次上市前五个交易日等例外，因此不能统一硬编码 10%。[深交所风险揭示书第十三条](https://docs.static.szse.cn/www/lawrules/service/member/W020260424702381159118.pdf)

## 第一阶段的五组证据

第一阶段展示独立指标、样本和反向证据。暂不设置未经校准的加权总分，也不直接迁用旧项目按累计二板次数划分强弱的阈值。

### 梯队高度和接力

令 D(g,W) 为 W 内可完整判定题材梯队的交易日集合。持续度的分子和分母都只取 D；D 为空时显示缺失。不完整日期中已经核验的高板股可单独展示为部分证据，不纳入该比例。

| 指标 | 计算口径 | 必须同时展示 |
| --- | --- | --- |
| 当日梯队 | 对 U(g,T) 分别统计 K=1、2、3、4、K>=5 的不同股票数 | 各层股票明细、板数未知和归属待核验数量 |
| 三板持续度 | D 中至少有一只 K>=3 股票的天数 / D 的天数 | 有效天数/计划天数；缺失日期不当成零 |
| 四板持续度 | D 中至少有一只 K>=4 股票的天数 / D 的天数 | 与三板相同；区分持续高标与新股接力 |
| 新三板/新四板 | W 内发生 2→3 或 3→4 事件的不同股票数，并另列事件数 | 股票、首次事件日期；同一股票不同周期可有多个事件 |
| k→k+1 晋级率 | s 日 K=k 且 s+1 日继续收盘涨停的数量 / 该队列中 s+1 状态可判定的数量 | 原始队列数、可判定数、缺失数、停牌数，分开呈现 1→2、2→3、3→4 |

晋级率使用 s 日冻结队列及归属，不采用次日新增题材成员。已确认停牌属于可判定但未晋级；行情未知不进入可判定分母，另报覆盖率。跨日汇总时按分子和分母求和，不把各日百分比简单平均；同时报告股票日事件数和不同股票数，说明重复样本。

三板、四板持续出现可能来自一只高标，也可能来自多只股票轮流接力，必须同时看持续天数、新晋股票数与梯队结构。高度只是证据之一，不能单独认定主流。

### 涨停队列的后续表现

固定追踪 C(g,s)，不因股票后来下跌、退市或退出题材而从历史样本中删除。设 P 为 s 日收盘价，O1、C1 为下一交易日开盘价和收盘价，各价格使用同一可追溯的复权基准。

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 次日开盘溢价 | O1 / P - 1 | 观察涨停后的隔日开盘反馈 |
| 次日收盘表现 | C1 / P - 1 | 观察反馈能否保持到收盘 |
| 次日开盘至收盘表现 | C1 / O1 - 1 | 区分高开后延续和高开后回落 |
| 两日/三日延续 | C(s+k) / P - 1，k 分别为 2、3 | 观察固定队列的后续延续，逐个周期计算成熟样本 |
| 正表现比例 | 对某个明确周期，结果 >0 的数量 / 该周期有效样本数量 | 展示普遍性，不能只用少数大涨股票抬高均值 |

每个指标至少给中位数、有效样本数、原始队列数、覆盖率和股票明细；可补充分位数。零收益不计为正。尚未走完观察周期的队列标记“待观察”，不能把短周期结果冒充三日结果；停牌不以复牌日代替固定的下一交易日。

在 T 日收盘时，C(g,T) 的次日表现尚不存在。此时只能使用截至 T 已成熟的历史队列，例如 C(g,T-1) 的次日结果。历史 T 日重放也必须按同样限制读取，不允许加载 T+1 数据后倒算 T 日建议。

观察涨幅不等同于可成交收益。尤其是一字板、排队成交、费用和触发时点均会改变实际可参与结果；它们不能从上述收盘比较中自动推导。

### 扩散广度

| 指标 | 定义 | 数据前提 |
| --- | --- | --- |
| 涨停密度 | 当日收盘涨停股票数 / 题材内当日正常交易、适用涨跌幅限制且涨停状态可判定的股票数 | 历史时点题材成分、适用制度及完整行情 |
| 上涨广度 | 当日涨幅 >0 的股票数 / 题材内当日涨幅可判定的正常交易股票数 | 可比较的当日涨幅；平盘列入分母，不列入分子 |
| 首板扩散 | 当日 K=1 数量，并对照前几日首板数量及新出现的不同股票 | 连板事实与完整度 |
| 参与规模 | 成员总数、有效交易数、涨停不同股票数 | 同时列缺行情、停牌、无价格限制的数量 |

同时查看数量和比例，避免大题材天然占优，也避免两只股票的小样本被夸大。多个题材之间可能重叠，市场汇总按股票去重，不直接把题材涨停数相加。

### 相对市场表现

相对强度采用“题材当日有效成分收益率中位数 - 对应市场样本收益率中位数”；历史涨停队列的次日表现也可与同期市场涨停队列比较。基准样本、覆盖范围、价格口径和时点必须固定并保存。

优先按市场及适用涨跌幅制度分组比较；跨制度汇总应另给分组结果。没有完整市场样本时显示“基准不足”，不能把当前界面中少量股票当作全市场。成交额与换手参与度可在可靠单位和历史口径齐备后补充。

### 负反馈

| 指标 | 定义与限制 |
| --- | --- |
| 高开低走比例 | C(g,s) 中 O1>P 且 C1<O1 的数量 / 次日 P、O1、C1 完整且可比较的样本数。基础定义不设幅度门槛；如增加门槛须版本化 |
| 次日收盘跌停比例 | 队列中次日收盘跌停数 / 次日正常交易、适用价格限制且收盘跌停状态可判定的数量，附原始队列覆盖率 |
| 高位断板反馈 | 固定 s 日 K>=3 的队列，展示次日未继续涨停数量，并分列实际收盘表现、停牌和未知，不把所有断板视为同一种下跌 |
| 距日高回落 | C1 / H1 - 1；反映收盘距离当日最高价的程度，不称作最大回撤 |

若要计算真实路径最大回撤，需要有时序的分钟或逐笔价格：按每个时刻相对此前累计最高值计算回撤，再取最差值。日线 H/L 无法证明最高点先于最低点。炸板、回封、首封和封板时长同样需要盘中事件覆盖，不能用日线猜测。

第二阶段可加入一字板占比、可参与性、成交额/换手参与度、核心股与跟随股分化、炸板回封。每项新增证据先明确数据来源与缺失状态，再进入题材建议规则。

## 系统建议与人工结论

“强势”用于描述近期相对表现及正反馈优势；“主流”用于描述跨多日持续的梯队接力、参与广度和市场影响。系统分别给出两类建议，而不是强行排列成一个互斥等级。

建议流程：

1. 校验截止时刻、观察窗口、样本覆盖、规则参数及历史归属版本。未满足参数所要求的最小覆盖时，输出“证据不足”。
2. 展示五组证据及反证。未配置建议规则时，提供观察项和人工判断入口，不猜测强弱标签。
3. 在已校准的规则版本下，输出建议标签和每条命中/未命中原因。窗口、阈值、最小样本量、排除范围作为具名参数保存。
4. 用户确认、调整或暂不判断，保存人工理由、操作时刻、适用日期和引用证据版本。人工修改不回写原始统计结果。
5. 数据更新产生新计算版本，保留旧建议和人工记录；提示可重新评估。已生成预案仍引用当时版本，不能静默替换。

第一版可提供最近 5/10/20 个交易日的观察窗口作为待验证的显示预设；这些不是认定强势或主流的阈值。建议规则上线前，至少整理强势接力、单股独强、高开低走、扩散转弱、小样本五类人工案例，检查指标能否解释用户判断，再选择参数。边界案例须保存异议，不能只挑吻合样本。

## 买卖点模式与候选生成

每个模式保存稳定 ID、名称、版本、允许的题材范围、收盘筛选条件、次日待观察条件、放弃条件及所需数据。现有手法词库继续保留，文字名称本身不代表已经具有机器可执行规则。

“强势题材二板”第一版规则：

- **截止时点**：T 日收盘资料完成核验后，以明确 as_of 生成；下一适用日由交易日历确定。
- **题材条件**：引用适用于 T 日、截至 as_of 已由用户确认的强势题材判断。仅系统建议但未确认的题材不自动混入。
- **股票条件**：股票属于所选题材的当时成员；T 日确认收盘涨停且 K=1。二板、高板、未知板数分别给排除或待核验原因。
- **合并规则**：股票跨多个入选题材时候选列表按证券 ID 去重，同时保留所有命中题材和依据。
- **输出**：T+1 候选及解释；下一日开盘、是否封二板、是否满足具体买点均是待观察内容。
- **人工完善**：填写具体触发、放弃、观察要求及适用的退出条件；不完整留草稿，允许删除候选或人工补充，人工补充单独标记理由。

适用对象是“下一交易日观察二板机会”的候选；次日是否涨停和买点是否成立分别记录。模式筛选不自动下单，也不根据后来结果补改前一晚的候选资格。

## 可验收的模拟案例

| 场景 | 预期 |
| --- | --- |
| 周四、周五、周一、周二连续收盘涨停，前一交易日非涨停 | 周二产生一次首达四板事件；周三继续涨停只增加五板存量 |
| 上述序列缺少周一行情 | 显示连续板数待核验；不能把下一条导入日当作周一 |
| 窗口中有一天只确认高板股，但其余成员资料不完整 | 当天不进入持续度分子或分母；高板记录作为部分证据另列，比例不超过 100% |
| 周一确认停牌 | 不满足连续四个交易日涨停，与行情缺失分别显示 |
| 原始记录“10 天 2 板” | 保留原文和区间字段；不能得到 K=10 或无依据得到 K=2 |
| 某历史涨停队列有 3 只股票，两只次日 P/O/C 分别为 10/10.2/10.5 与 20/20.6/19.6，另一只停牌 | 有效价格样本 2/3；收盘表现中位数 1.5%，正表现 1/2，高开低走 1/2；停牌不填零 |
| T 日强势题材甲有 A 首板、B 二板；题材乙也有 A；未确认题材丙有 C 首板 | 若只选甲乙，候选为 A 一只并保留两条题材依据；B 排除、C 不自动入选 |
| T+1 A 未满足买点或出现亏损走势 | T 日候选及依据保持原样；在次日观察记录中写结果 |
| T+2 新增股票的历史题材归属 | 不能在重放 T 日时当作当时已知归属；修订研究另存版本 |
| 同一股分属两个题材、连续多日涨停 | 各题材内正确去重；市场总数去重；股票日事件数与不同股票数分开 |
| 复权、无价格限制、退市、分母为零、窗口未成熟 | 不同状态明确显示，不输出虚假的 0% 或完整结果 |
| 截止 T 重放时系统持有 T+1 完整数据 | 截断后得到与 T 当时一致的候选和建议输入，未来记录不可读取 |

指标需要人工可计算样本验证；模式需要按时间划分校准与检验样本，记录费用、可成交性和信息可知时间后才讨论策略表现。本阶段先完成可解释事实、候选资格和观察闭环。
