# 当前范围与后续优先级

这是范围与优先级记录，不是已承诺的交付日期。具体工作在 `codex/dev` 持续开发，按功能提交和构建，按用户要求整理阶段 PR；验收结果保留在交接记录，有阶段 PR 时汇总到 PR。

## 已实现的前端预览

- Rust + GPUI 原生应用，Windows MSVC Release ZIP，Linux 构建与离屏渲染验证。
- 十一类业务面板：自选、图表、关键数据、十档盘口、成交明细、逐笔成交、委托明细、资讯、模拟交易、订单与持仓。
- 窗口内停靠、独立窗口、跨窗迁移、联动组、布局模板、撤销、自动保存与旧文件保护。
- 新增组件默认独立窗口，支持组件标题拖动及按目标/方向重新插入，保留当前浅色配色。
- 顶部自定义看板栏，独立组件组合、布局和浮窗；支持命名、复制、排序、删除与旧单布局迁移。
- 分时/日 K/周 K/月 K/1 分/5 分、价格与成交量均线、十字线、缩放和平移；确定性模拟行情与当前会话的模拟账户。

代码与自动验证已具备上述能力；Windows 混合 DPI、中文输入法和完整原生桌面流程仍需实机验收。
