# 当前范围与后续优先级

这是范围与优先级记录，不是已承诺的交付日期。具体工作在 `codex/dev` 持续开发，按功能提交和构建，按用户要求整理阶段 PR；验收结果保留在交接记录，有阶段 PR 时汇总到 PR。

## 已实现的前端预览

- Rust + GPUI 原生应用，提供 Windows MSVC Release ZIP 和 Linux 构建/离屏检查流程；使用原生控件与绘图，不嵌入网页。
- 已按 React 设计复刻行情、盯盘、涨停、题材、复盘五页前端，统一浅色/青色视觉、导航、全局搜索、个股速览和状态反馈。
- 十一类业务面板：股票列表、图表、关键数据、十档盘口、成交明细、逐笔成交、委托明细、资讯、模拟交易、订单与持仓。
- 组件可自定义名称；每个股票列表为独立分组，可添加/移除现有模拟目录中的股票，保留空列表、搜索与排序。
- 股票列表可从粘贴文本或 TXT/CSV 批量导入，自动识别、预览、去重并提示目录外代码，确认后仅追加到当前分组。
- 窗口内停靠、独立窗口、跨窗迁移、联动组、布局模板、撤销、自动保存与旧文件保护。
- 新增组件默认独立窗口，支持组件标题拖动及按目标/方向重新插入，保留当前浅色配色。
- 顶部自定义看板栏，独立组件组合、布局和浮窗；支持命名、复制、排序、删除与旧单布局迁移。
- 分时/日 K/周 K/月 K/1 分/5 分、价格与成交量均线、十字线、缩放和平移；确定性模拟行情与当前会话的模拟账户。
- A 股分时固定全天时轴、竞价参考价与实际撮合区分、午休分界、未来留白与盘后保留；股票目录共 18 只，其中 12 只 A 股，保留旧美港股样例及所属市场时段，不自动扩充用户已有列表。
- 分时单击开关十字线与左右吸附数据卡，鼠标/键盘逐分钟定位，显示对应分钟量额和累计均价；历史分时同样支持。
- 日 K 点击定位、左右吸附详情卡和键盘逐根查看；双击打开对应日的历史分时，支持前后交易日导航，分钟数据与模拟日 K 量价一致。
- 独立盯盘分组及成员管理、列数/排序、全局监控和静音状态、规则编辑、手动生成演示异动与个股跳转。
- 涨停多日板块矩阵、字段文本 AND 搜索、资料编辑、样例导入和整日删除/恢复；题材对象、四日周期、梯队、八日关键词及截止日联动证据展示。
- 复盘按日预案、多个独立草稿、仅卖出预案、盘中笔记、人工热点/手法/手工收益和独立原生阅读窗口；输入校验及按 ID 编辑。
- 显式跨页路径：资料 → 题材/个股速览 → 选择业务日引用草稿，或预览去重后加入盯盘，保留原资料日期和依据。
- 独立 `desktop.json` 保存新业务数据，防抖写入、有效旧文件备份、坏文件与外部改动保护；行情 `workspace.json`、旧 Dock 协议和布局撤销保持兼容。

上述为当前代码实现范围。具体构建和交互检查以对应提交的实际报告为准；Windows 混合 DPI、中文输入法和完整原生桌面流程仍需实机验收。React 样机继续用于设计对照，浏览器存储不与原生文件互通。

## 研究与监控尚未完成的业务

五页复刻完成的是原生前端和本地状态，不是附件 42 的全部旧应用能力。涨停导入当前加载内置样例，尚无完整旧格式文件兼容、文件指纹去重或全部日期/连板查询；题材周期、梯队、关键词、归属和月热点仍为固定样例，资料编辑不会驱动真实算法重算。盯盘通过按钮生成演示事件，尚无真实轮询、采样计算、冷却/计次或系统语音。手工收益不等于账户核算。

后续研究算法对齐应使用脱敏输入和黄金输出，分别验收累计次数、板数优先级、截止日与回退逻辑，不能用 UI 出现某个字段替代算法证据。真实行情和数据库迁移另行定义任务范围。
