# Tydaro 桌面设计预览

使用 React + TypeScript + Vite 构建的可交互设计样机，供后续 Rust / GPUI 原生界面复刻。沿用项目浅色配色，重点验证 A 股行情工作台的信息层级、看板组合、股票分组和图表检视，不替代仓库中的原生应用。

![Tydaro 浅色行情工作台](../docs/design-preview.png)

## 运行与交付

使用 **Node.js 24**，在本目录执行：

```bash
npm ci
npm run dev
```

开发服务器使用 Vite 输出的地址。在云环境中访问需要使用环境提供的端口转发；浏览器中的本机地址不等于云机器地址。

```bash
npm run build
```

构建先检查 TypeScript，再生成 `dist/` 静态资源和独立文件 **`dist/tydaro-preview.html`**。下载该 HTML 后可在桌面浏览器双击离线打开；无需 Node 服务，也不会请求行情接口。开发依赖安装和构建仍需要 Node。预览不依赖在线字体或图片。

```bash
# 使用云环境已安装的 Chromium
CHROMIUM_PATH=/usr/bin/chromium npm run test:ui

# 同一交互集验证 React 开发模式与 StrictMode
PREVIEW_DEV=1 CHROMIUM_PATH=/usr/bin/chromium npm run test:ui

# 或使用 Playwright 自己管理的浏览器
npx playwright install chromium
npm run test:ui
```

`test:ui` 执行真实浏览器交互检查。指定 `CHROMIUM_PATH` 时使用该可执行文件，否则使用 Playwright 默认浏览器。检查结果以实际命令输出为准；它不验证 Windows 原生应用或跨显示器 DPI。

构建产物无需联网加载字体、脚本或样式。当前云浏览器禁止 `file://`，本地验收对单文件使用 HTTP 加载并阻止额外资源请求；该限制与页面运行错误分别记录在检查报告中。

## 建议体验顺序

1. 切换「A 股全景」「短线观察」「趋势研究」，观察分组、选股和布局各自保留；也可新建看板。
2. 在左侧列表选股，用搜索和沪深筛选缩小范围；通过列表菜单改名、添加、移除或从文本批量导入。
3. 点击分时成交区域开启十字线，移动或用方向键定位；数据卡吸附在另一侧，再次点击收起。午休和未来区域没有成交点。
4. 切换日 K，检视蜡烛数据；双击蜡烛打开历史分时流程示例。可使用图表专注模式。
5. 添加组件后先出现浮窗。拖动标题移动，用右下角尺寸手柄调整大小，通过「插入面板」选择主图区域的上、下、左、右；关闭浮窗即移除，可在提示中撤销。
6. 用 `Ctrl/Cmd + K` 搜索股票，体验布局锁定、分栏调整和紧凑密度。

## 文件职责

| 文件 | 内容 |
| --- | --- |
| `src/App.tsx` | 工作台、看板、股票列表、组件库、浮窗、弹窗与操作状态 |
| `src/styles.css` | 浅色设计变量、桌面尺寸、排版与交互样式 |
| `src/Chart.tsx` | SVG 图表、A 股时轴、十字线和检视卡 |
| `src/data.ts` | 12 只样例股票、看板模型、简化停靠树和文本识别 |
| `scripts/` | 浏览器检查与离线交付构建脚本 |

## 预览边界

- 行情、指数、盘口、资讯及历史曲线均为静态模拟；关键数据摘要、盘口与图表使用各自的演示数据，未校准量额聚合，不作为行情计算一致性的验收依据。
- 预览拥有独立的 **12 只 A 股**目录，不改变 Rust 当前 8 只样例目录。粘贴导入只识别预览目录，未识别项会提示；不提供原生版本的文件选择与多编码导入。
- 看板和成员状态只在本次页面会话保留，刷新恢复初始值，不读写原生布局。附加股票列表展示自己的成员快照；完整改名、添加、移除和导入流程集中在左侧主列表。
- 网页浮窗是同一页面内的元素，拖动与 CSS `resize` 不等于系统窗口。四向插入仅拆分中间主图工作区，没有完整 DockArea、任意目标拖放、标签合并或跨系统窗口迁移。
- 历史分时用于验证“日 K 双击打开”的流程，曲线不按所选日重建，未与该蜡烛 OHLC、量额逐项校准。图表周期和选股按看板共享，原生版本仍保留每个组件自己的周期和联动组。

完整设计依据、GPUI 对应模块和原生验收要求见 [设计说明](../docs/design-preview.md)。
