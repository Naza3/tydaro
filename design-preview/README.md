# Tydaro 统一桌面设计预览

使用 React + TypeScript + Vite 构建的可交互设计样机。Rust / GPUI 主程序现已复刻行情、盯盘、涨停、题材、复盘五页前端，本目录继续保留为信息组织、视觉和操作路径的对照。原生界面使用 GPUI 控件，不运行这份网页；两版的存储与窗口能力不同，也都不代表附件功能基线的全部算法与真实数据已经实现。

![Tydaro 统一行情工作台](../docs/design-unified/market.png)

## 五个页面，一条工作流

| 页面 | 主要任务 | 可体验的交互 |
| --- | --- | --- |
| 行情 | 深看一只股票 | 自定义看板、独立股票列表、图表检视、组件浮出与四向插入 |
| 盯盘 | 同时扫描多个观察分组 | 分组增删改、成员管理、列数和排序、规则编辑、手动演示异动、个股速览 |
| 涨停 | 整理和筛选原始资料 | 多日板块矩阵、AND 条件、明细编辑、示例导入、整日删除与恢复、跨页引用 |
| 题材 | 看对象、证据和联动 | 触发区间、实际截止日、周期与关键词切换、联动股票、复制及加入盯盘 |
| 复盘 | 写下判断，盘中查阅 | 按日期保存预案和草稿、人工热点、买卖手法、手工买入记录、阅读浮窗 |

建议先在「涨停」筛选资料，进入「题材」查看证据，再用「引用为预案」选择业务日期并补充条件，最后把相关股票加入「盯盘」。加入分组会预览新增、重复与目录外代码；引用预案创建独立草稿，不覆盖已有内容。点击股票可在个股速览中查看图表，再返回原页面，或打开行情继续研究。

人工热点、研究结果与股票分组保持独立。页面自己的日期也独立：研究截止日不会改变复盘日期或演示行情快照。

## 运行与交付

使用 **Node.js 24**，在本目录执行：

```bash
npm ci
npm run dev
```

开发服务器使用 Vite 输出的地址。在云环境中访问需要使用环境提供的端口转发；浏览器中的本机地址不等于云机器地址。

```bash
npm run build
```

构建先检查 TypeScript，再生成 `dist/` 静态资源和独立文件 **`dist/tydaro-preview.html`**。下载该 HTML 后可在桌面浏览器离线打开，无需 Node 服务，不请求行情接口，不依赖在线字体或图片。开发依赖安装和构建仍需要 Node。

```bash
# 使用云环境已安装的 Chromium
CHROMIUM_PATH=/usr/bin/chromium npm run test:ui

# 同一交互集验证 React 开发模式与 StrictMode
PREVIEW_DEV=1 CHROMIUM_PATH=/usr/bin/chromium npm run test:ui

# 或使用 Playwright 自己管理的浏览器
npx playwright install chromium
npm run test:ui
```

`test:ui` 执行真实浏览器交互检查；指定 `CHROMIUM_PATH` 时使用该可执行文件，否则使用 Playwright 默认浏览器。结果以实际输出为准，不验证 Windows 原生窗口或跨显示器 DPI。若环境策略禁止 `file://`，可通过 HTTP 验证同一内联 HTML 并检查额外资源请求；这不能替代本地文件打开的实测结果。

[Design preview 工作流](../.github/workflows/design-preview.yml) 使用 Node.js 24、锁文件安装和 npm 下载缓存，执行生产构建与 Chromium 检查，上传 `dist/` 及 `artifacts/` 报告和截图。它独立于原生 Rust 构建。

## 更多体验

1. 在行情切换「A 股全景」「短线观察」「趋势研究」，观察各自分组、选股和布局；也可新建看板。
2. 用行情左侧列表菜单改名、添加、移除或从文本批量导入。单击分时成交区域开启十字线，移动或用方向键定位，数据卡吸附到另一侧，再次单击收起。日 K 双击打开历史分时流程示例。
3. 添加行情组件后先出现浮窗，拖动标题、调整尺寸，再从「插入面板」选择主图区域的上、下、左、右。关闭即移除，可撤销。
4. 在盯盘调整分组列数，点「演示异动」，再从异动记录定位股票。暂停控制演示事件生成，静音仅切换界面状态。
5. 在复盘只填写卖出侧也可以形成预案；不完整内容保留草稿。打开阅读浮窗，查看预案并编辑同一天的盘中记录。
6. 用 `Ctrl/Cmd + K` 搜索股票或页面，用 `Esc` 关闭当前弹层；模态编辑期间先完成或关闭弹窗再搜索跳页；「偏好」提供新页面的表格密度切换。

## 保存范围与演示边界

- **复盘内容**保存在当前浏览器的 `localStorage`，键为 `tydaro.preview.journal.v2`。预案、草稿、盘中记录、人工热点、手法及手工买入记录在修改后 700 ms 防抖保存，并提供立即保存。浏览器禁止存储时仅保留本次会话；写入失败显示错误并保留内存内容；损坏数据不会自动覆盖，先只读展示示例，可重试或选择仅本次会话继续。它不是 SQLite、文件备份或跨浏览器同步，未保存成功的内容刷新后可能丢失。
- **行情看板、盯盘分组、规则、异动、研究编辑、筛选和显示偏好**只在本次页面会话保留，刷新恢复样例。切换页面保留当前 React 实例，不读取或改写原生布局、数据库。
- 全部行情、指数、盘口、资讯、月热点和研究结论均为演示样本。题材页展示固定的周期、梯队和关键词证据；涨停页的导入/编辑/删除不会重新计算题材页。导入按钮载入内置资料，不是旧格式 CSV/TXT 兼容解析器。搜索为字段文本 AND 匹配，未实现功能基线中的全部日期范围和特殊连板/联动查询。
- 盯盘没有真实行情轮询、采样窗口、冷却/每日计次或系统声音；规则用于手动演示提醒。未实现文档 42 的完整预警与月热点算法，不以界面出现某个数值表示业务已对齐。
- 预览拥有独立的 **12 只 A 股**目录；原生目录目前为 **18 只，其中 12 只 A 股**，保留旧美港股样例且不向已有股票列表自动追加。浏览器粘贴导入只识别预览目录，未识别项会提示；不提供原生版本的文件选择与多编码导入。
- 网页浮窗是同页元素，拖动与 CSS `resize` 不等于系统窗口。行情四向插入仅拆分中间主图区域，没有完整 DockArea、任意目标拖放、标签合并或跨系统窗口迁移；新研究页面不提供任意拆分停靠。
- 行情关键摘要、盘口与图表使用各自样例，未校准量额聚合。历史分时不按选定日重建，未与该蜡烛 OHLC、量额校准。行情周期和选股按看板共享，原生每组件周期及联动组仍独立；附加股票列表只展示自己的成员快照，完整成员管理集中在主列表。

## 与 GPUI 原生版本的区别

原生五页由 `src/desktop.rs`、`desktop_ui.rs`、`watch_page.rs`、`research_page.rs` 和 `journal_page.rs` 实现，跨页来源与本地业务状态集中于 `desktop_state.rs`。行情继续使用原有 DockArea、看板、组件身份、原生图表和历史分时逻辑；新页面不改写用户的旧布局格式。

原生将盯盘分组、规则、演示异动、复盘和已确认的涨停资料修改保存到独立 `desktop.json` schema `1`，行情布局仍在 `workspace.json`。它具有防抖保存、有效旧文件 `.bak`、字段校验和损坏/外部改动拒绝覆盖的保护；保存失败时修改仅留当前进程内存。浏览器 `localStorage` 不会自动迁移到原生文件，两版数据不共享。原生复盘阅读窗口是真实 GPUI 窗口，与这里的页面内浮窗不同。

两版都保留模拟标识：涨停样例导入不是旧格式文件兼容器，题材证据不会随资料编辑重算，盯盘演示按钮不是实时监控服务。React 浏览器检查不代表 GPUI 构建或原生窗口验证，更不能替代 Windows 字体、中文输入法与混合 DPI 的实机验收。

## 文件职责

| 文件 | 内容 |
| --- | --- |
| `src/UnifiedApp.tsx`、`src/workspace-model.ts` | 五页外壳、全局搜索、个股速览、跨页上下文与分组追加 |

| `src/unified.css`、`src/ui.tsx` | 统一视觉、外壳控件与通用对话框 |
| `src/Chart.tsx`、`src/data.ts` | SVG 图表、A 股时轴、12 只股票、简化停靠树与文本识别 |
| `scripts/` | 浏览器检查与离线交付构建 |
